## Features (4 pilares + módulos)

**Pilares:** Track · Budget · Collaborate · Plan.

| Módulo | O que faz |
|---|---|
| **Track / Net Worth** | agrega bancos, cartões, empréstimos, **investimentos e imóveis**; net worth + cash flow |
| **Budget** | orçamento flexível que adapta |
| **Collaborate** | convidar parceiro/advisor (grátis), visão compartilhada, atribuir transação pra revisar |
| **Plan / Goals** | metas com ajuste de cash flow + progresso |
| **Transactions** | lista unificada buscável, marcar como revisado |
| **Recurring** | detecção automática de assinaturas |
| **Reports** | gráficos custom de tendência de gasto |
| **Bill calendar** | calendário de contas |
| **Data connectivity** | **13.000+ instituições** (agregação tipo Open Finance, via Plaid/MX no mercado US) |
| **Mobile** | iOS + Android com sync |
| **Plus extras** | business income/expenses, P&L, tax-prep exports, retirement forecast, criar testamento |

## Casais (`/for-couples`)

- *"Your entire household in a single dashboard"*: contas separadas + conjuntas numa visão; gasto "como household, não importa quem comprou"; net worth conjunto.
- *"Collaboration made easy"*: **atribuir transação pra revisar** (Anyone/parceiro A/B); money check-ins (resumo mensal + relatórios); orçamento com flexibilidade pros dois.
- *"Go further, together"*: metas compartilhadas.
- **Parceiro grátis** (no extra cost).
- **Modelo = merge + atribuição.** Sem rateio/split/papéis/dependentes/aprovação.

## Profissionais (`/for-professionals`)

Advisors (consultores financeiros) colaboram com clientes sem licença extra. Adjacente — mas é advisor, não contador fiscal.
